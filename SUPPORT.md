# Support

This free, community-driven project welcomes questions, bug reports, and feature ideas.

## Getting help

- Setup or usage questions: check the [README](README.md), especially [Installation & Setup](README.md#installation--setup), [Environment Variables](README.md#environment-variables), and [Usage](README.md#usage).
- Something is broken: open a [bug report](.github/ISSUE_TEMPLATE/bug_report.md).
- You have an idea: open a [feature request](.github/ISSUE_TEMPLATE/feature_request.md).
- General questions or discussion: open a regular GitHub issue. The project has no separate forum or chat.
- Security issue: do not open a public issue. See [SECURITY.md](SECURITY.md).

## What to expect

This is a personal project maintained on a best-effort basis. There is no SLA or guaranteed response time. Issues and pull requests are reviewed when time allows.

## No financial support needed or wanted

The project does not accept donations, sponsorships, or other financial contributions. You can help by reporting bugs, suggesting features, improving the docs, or submitting a pull request. See [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

## Before you ask

Before reporting an issue, update to the latest `main` commit and follow the [README setup steps](README.md#installation--setup), including setting `OPENAI_API_KEY`. Missing setup is a common cause of reported problems.
