# Support

Welcome! This project is free and community-driven, and questions, bug reports, and feature ideas are all genuinely welcome.

## Getting help

- **Setup or usage questions** — check the [README](README.md) first, especially [Installation & Setup](README.md#installation--setup), [Environment Variables](README.md#environment-variables), and [Usage](README.md#usage). Most "why isn't this working" questions are answered there.
- **Something's broken** — open a [bug report](.github/ISSUE_TEMPLATE/bug_report.md).
- **You have an idea** — open a [feature request](.github/ISSUE_TEMPLATE/feature_request.md).
- **General questions or discussion** — open a regular GitHub issue; there's no separate forum or chat for this project.
- **Security issue** — do not open a public issue; see [SECURITY.md](SECURITY.md) instead.

## What to expect

This is a personal, single-maintainer, best-effort project. There's no SLA and no guaranteed response time — issues and PRs get looked at when time allows. That said, all feedback is read and appreciated, even if a reply takes a while.

## No financial support needed or wanted

This project does not want or accept donations, sponsorships, or any other form of financial contribution. If you'd like to support the project, the most valuable things you can do are: report bugs, suggest features, improve the docs, or submit a PR. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Before you ask

Please make sure you're on the latest commit on `main` and have followed the [README setup steps](README.md#installation--setup) exactly (including having `OPENAI_API_KEY` set) before reporting an issue — a large share of "bugs" turn out to be missing setup steps.
